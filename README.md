# Cinema Management System

## Project Description

A Java-based Cinema Management System using MySQL and JDBC to manage movies, shows, seats, bookings, and payments.

## Technologies Used

* Java
* MySQL
* JDBC
* Eclipse IDE
* MySQL Connector/J

## Database Setup

1. Open MySQL Workbench.
2. Open `database/schema.sql`.
3. Execute the SQL script to create the database and tables.
4. Configure the database connection using your local MySQL credentials.
5. Run the Java application from Eclipse.

## Database Name

`CinemaManagement`

## Security

* Never upload real database passwords to GitHub.
* Keep `db.properties` private.
* Use `db.properties.example` as a configuration reference.

## Main Components

* Models
* Data Access Objects (DAOs)
* Services
* Database connection configuration
